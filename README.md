# Sanjo Buchhaltung

Eine Buchhaltungssoftware für Deutschland.

> [!NOTE]
> Ich teste die Software aktuell selber. Aktuell nur empfohlen für Leute, die Bugs ggf. selber mit Codex fixen können.

## Geplante Features

* Doppelte Buchführung
* Jahresabschluss
* E-Bilanz
* Umsatzsteuer-Voranmeldung und Umsatzsteuererklärung
